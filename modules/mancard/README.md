# Модуль Mancard - Управление организациями и сотрудниками

## Описание
Модуль для управления организационной структурой и сотрудниками.

## Функциональность
- Просмотр дерева организаций
- Добавление/удаление/переименование организаций
- Перемещение организаций (включая корень)
- Просмотр сотрудников организации
- Добавление/удаление/редактирование сотрудников
- Массовое перемещение сотрудников между организациями
- Drag & Drop для организаций

## Установка
1. Скопировать папку `mancard` в `application/modules/`
2. Добавить в `bootstrap.php`:
```php
Kohana::modules(array(
    // ...
    'mancard' => MODPATH.'mancard',
    // ...
));
